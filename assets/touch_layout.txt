# =====================================================================
#  Layout de los mandos tactiles de AllGenURecomp Android
#
#  Coordenadas NORMALIZADAS sobre la PANTALLA (0,0 = arriba-izquierda,
#  1,1 = abajo-derecha). El telefono se usa en horizontal: x crece a la
#  derecha y las zonas de "abajo" son el borde que queda en tu mano.
#
#  Formato:
#     tipo     id     x      y      r      [h]
#       button  A|B|X|Y|L|R|ZL|ZR|PLUS|MINUS|UP|DOWN|LEFT|RIGHT   r = radio
#       stick   L|R                                                r = radio
#       dpad    D                                                  r = radio
#       camera  R   (o L)                                          r = medio ancho, h = medio alto
#                                                     (zona de arrastre, raton -> stick derecho)
#
#  Reglas que aplican:
#   - Un dedo que empieza dentro de un stick sigue controlándolo aunque se salga
#     del circulo (para girar sin levantar el dedo).
#   - Los botones son multitáctiles: A + stick izquierdo a la vez funciona.
#   - Zona muerta del 18 % del radio del stick (evita deriva).
#
#  Para cambiar el layout: copia este archivo a
#     /data/data/com.kriszts.allgenu/files/touch_layout.txt
#  y reinicia la app. No hace falta recompilar.
# =====================================================================
